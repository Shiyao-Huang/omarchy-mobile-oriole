# Public publication record

This snapshot was prepared for public GitHub publication from local commit `f7534b7d76b6cd78bb923188109ea022f0806c84`.

The release boundary is source/evidence only. The audit removes machine-specific paths, screenshots, host logs, private backups, credentials, vendor firmware and binary phone images. A contributor can inspect the source and reproduce offline contracts, but cannot reproduce a hardware claim without the exact kernel build, an unlocked test phone and user-supplied firmware/calibration.

Before every checkpoint, the project records a claim, oracle, user journey, code reasoning, unit cases, end-to-end boundary, limits and an exit gate. The latest manifest deliberately keeps open gates visible instead of presenting the port as finished.
